# Comportement comparé à GNU sort 9.12

Le tableau porte sur les exemples effectivement exécutés. Le détail par graphie donne les arguments, la locale, les statuts, les empreintes stdout, stderr et les fichiers relus. Le jeu rapide contient 107 cas. Les trois suites Perl GNU et les scripts shell lancés sur le même Mac complètent ce jeu. Les témoins supplémentaires couvrent le nom non UTF-8, les décimales françaises, la collation aléatoire et une erreur injectée à la décompression. Les fonctions de caractères du cœur privilégient les octets et les transformations ASCII. Darwin emploie `strcoll`, `strxfrm`, `strtod` et les paramètres locaux de libc. Le témoin NovaOS emploie la collation C. Les 30 jeux du témoin embarqué incluent leurs sorties de référence et n’acquièrent aucun droit sur un fichier. Les sorties du pipe métier sont comparées séparément. [Vecteurs GNU](src/golden.rs) · [Banc natif](lab/guest.py) · [Banc avec le catalogue récepteur](lab/pipe_recepteur.py)
