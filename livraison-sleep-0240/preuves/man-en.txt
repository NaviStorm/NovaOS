NAME
     sleep - wait for the sum of the durations

SYNOPSIS
     sleep [--] duration ...
     sleep --help | --version

DESCRIPTION
     A duration is a nonnegative decimal or hexadecimal number, optionally
     followed by s, m, h or d for seconds, minutes, hours or days. The default
     unit is seconds.  Use inf to wait indefinitely. The first recognized
     option takes effect immediately.

EXAMPLES
	   sleep .025 1e-3s

EXIT STATUS
     Zero on success, one for invalid input or an error during the wait.

RIGHTS
     Documentation needs only output. A positive wait in NovaOS uses a private
     IPC endpoint. The command does not read stdin or access files.
