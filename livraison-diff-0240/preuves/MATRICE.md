# Cas conformes par cible

Chaque cellule donne le nombre de cas conformes au statut et aux deux flux de référence. Les colonnes invitées concernent le moteur dans l’ELF de recette. Les identifiants, valeurs, combinaisons, opérandes, entrées standard et octets attendus sont dans [le relevé Darwin](complet/options.json). Les identifiants en écart sont journalisés individuellement par chaque invité. Le [rapport](../README.md) décrit les essais sur les fichiers P9 réels et le shell ordinaire.
