# Les 37 commandes à conserver

Les noms et contrats proviennent du catalogue qualifié sur la [branche documentaire de phase 2](https://github.com/NaviStorm/NovaOS/blob/09b2d96faeb4eb3c98881be99c245975c358abb6/components/libraries/documentation.rs). Huit pages pilotes sont intégrées à la base officielle de cette étude. Les 29 autres **commandes métier existent déjà** sur cette base ; leur couverture ARC-026 complète est qualifiée sur la branche séparée. Ces résultats concernent les sources et les profils QEMU, pas l’image UTM v0.17.0. Composants nsh et nova-cli 0.20.0 ; les versions de noyau, de SDK et d’outil suivent leurs propres manifestes.

Les règles de flux, d’aide, d’options et de tests communs figurent dans le [contrat ARC-027](README.md). La dernière colonne identifie l’oracle et un écart à conserver ou arbitrer. Pour les internes spécifiques à NovaOS, le catalogue et l’implémentation propres constituent l’autorité. Les passages futurs sur pipes et les extensions proposées pour ps et top exigent une nouvelle qualification. Les estimations de réutilisation figurent dans les [lots](lots.md).
