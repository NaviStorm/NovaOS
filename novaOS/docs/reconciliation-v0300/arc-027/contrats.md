# Contrats à construire ou à étendre

Ces profils sont proposés pour arbitrage. Chaque ligne hérite des conventions de flux, erreurs, localisation et qualification du [contrat commun](README.md) et du responsable, des budgets et des tests du [lot indiqué](lots.md). Les mots en majuscules dans un synopsis sont des opérandes. Les crochets décrivent l’optionalité. Les alternatives séparées par une barre verticale sont des formes distinctes. La colonne des références renvoie aux [révisions et licences](sources.md). La colonne des différences consigne les limites de compatibilité à trancher avant publication d’une option. Les 37 commandes présentes ont leur [matrice propre](existantes.md).

Les sous-commandes de diagnostic et de pare-feu sont regroupées sous les noms de travail `storage`, `volume` et `firewall`. La correction MOA est portée par la seule ligne `uname`.

## Formes longues et choix de compatibilité

Les alias suivants sont des propositions de profil visant le même opérateur que la forme courte indiquée. Les exercer avec valeurs séparées et accolées lorsque la référence le permet. Une absence dans ce tableau ne vaut ni une option implémentée ni une décision de rejet définitif. Les [relevés amont](parametres-amont.md) et le registre d’écarts permettent d’arbitrer les extensions. Pour les commandes natives d’administration, les formes longues définies dans les synopsis sont canoniques.

| Commande | Correspondances proposées ou décision de grammaire |
|---|---|
| grep | -F/--fixed-strings, -E/--extended-regexp, -e/--regexp, -i/--ignore-case, -v/--invert-match, -n/--line-number, -c/--count, -l/--files-with-matches. Comparer l’effet de -q en présence d’une erreur avant de le proposer. |
| sed, awk | sed -n/--quiet, -E/--regexp-extended, -e/--expression, -f/--file. Pour awk cibler d’abord -F, -v et -f de l’interpréteur de référence ; les extensions --posix/--sandbox de gawk ne remplacent pas l’isolation de NovaOS. |
| find, xargs | Les primaires find -name, -type et -print0 ont un seul tiret. Pour xargs, -0/--null, -n/--max-args, -s/--max-chars et -P/--max-procs, avec plafonds mesurés. Ne pas appliquer un analyseur générique d’options aux expressions de find ni à l’argv de l’enfant. |
| sort, uniq | sort -n/--numeric-sort, -r/--reverse, -u/--unique, -k/--key, -t/--field-separator. uniq -c/--count, -d/--repeated, -u/--unique, -i/--ignore-case. |
| cut, tr, tee | cut -b/--bytes, -c/--characters, -f/--fields, -d/--delimiter, -s/--only-delimited. tr -d/--delete et -s/--squeeze-repeats ; distinguer les compléments de caractères et de valeurs selon l’oracle et la locale. tee -a/--append. |
| df, du, stat, file | df -h/--human-readable, -P/--portability, -i/--inodes (sens à valider pour P9). du -a/--all, -s/--summarize, -h/--human-readable. stat --format aligné GNU si retenu ; documenter la collision -f. file -b/--brief et -L/--dereference. Le candidat file utilise -i pour MIME selon le profil compilé, à vérifier avec sa base magic. |
| tar, gzip | tar -c/--create, -x/--extract, -t/--list, -f/--file, -C/--directory ; décider avant livraison les formes historiques sans tiret. gzip -c/--stdout, -d/--decompress, -t/--test ; pas d’effacement de source pour contourner le refus de remplacement. |
| id, uname | id -u/--user, -g/--group, -G/--groups, -n/--name. uname -a/--all, -s/--kernel-name, -n/--nodename, -r/--kernel-release, -v/--kernel-version, -m/--machine. |
| diff, cmp | diff -q/--brief, -u ou --unified (avec contexte dont le défaut est trois lignes), -r/--recursive. cmp -l/--verbose et -s/--silent. Distinguer résultat « différent » et erreur de lecture. |
| curl, SSH | curl -f/--fail, -s/--silent, -S/--show-error, -L/--location, -I/--head, -o/--output. Conserver les formes propres à OpenSSH (-p pour ssh, -P pour scp/sftp). Ne pas inventer une extension longue GNU pour ces clients. |

| Autres | Les profils initiaux à formes courtes, commandes sans option métier et sous-commandes natives conservent explicitement --help, --version et man. Les formes longues, abréviations et options de configuration d’un autre système demandent un cas de test avant publication. |
