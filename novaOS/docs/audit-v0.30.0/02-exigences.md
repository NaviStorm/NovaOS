# Matrice des exigences

Base et définitions des états dans le [dossier d’audit](README.md). La colonne « décision » distingue les acquis à préserver (socle), les exigences du mandat et les engagements encore à arbitrer. Les contrôles sont des critères proposés pour les prochaines campagnes.
